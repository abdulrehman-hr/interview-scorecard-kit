# Interview Scorecard Kit

A complete, structured-interview toolkit for hiring managers and HR professionals.
Built by **Abdul Rehman** — Senior HR Executive, 1000+ hires.

## Why structured interviews?

Unstructured interviews are little better than a coin flip. A structured interview —
the same questions, the same scorecard, scored independently — is one of the most
predictive hiring methods we have. This kit gives you everything you need to run one.

## What's inside

| File | What it is |
|---|---|
| `interview-scorecard.xlsx` | Weighted scorecard template (auto-calculates), rating scale, and question bank in one workbook |
| `question-bank.md` | 60+ categorized interview questions with "what to listen for" and red flags |
| `interviewer-guide.md` | Step-by-step guide: before, during, and after the interview, plus bias traps to avoid |

## How to use it

1. **Before:** Pick 6-8 questions from the question bank for the role. Fill in the
   candidate's details on the Scorecard sheet.
2. **During:** Ask every candidate the same core questions. Take notes, don't score yet.
3. **After:** Score each criterion 1-5 immediately after the interview, while it's fresh.
   The sheet calculates the weighted total and suggests a hiring recommendation.
4. **Decide:** Compare scorecards across interviewers before discussing — independent
   scoring beats groupthink.

## The rating scale

| Score | Meaning |
|---|---|
| 5 | Exceptional — clear evidence, best-in-class answer |
| 4 | Strong — solid evidence, above expectations |
| 3 | Acceptable — meets expectations, no concerns |
| 2 | Weak — below expectations, concerns |
| 1 | Poor — no evidence or major red flags |

## Customize it

Weights in the scorecard are a starting point. For a sales role, raise the weight on
communication; for an analyst role, raise it on problem solving. Keep weights
consistent across candidates for the same role.
